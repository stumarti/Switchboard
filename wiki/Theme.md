# Theme

An admin can re-skin every icon and the on-screen font from Switchboard Server's **Settings → Theme** (pick a font, search-and-replace any icon from Material Design Icons). The device downloads the compiled result automatically and loads it from its SD card, with no reflashing.

There's nothing to do on the device itself: a re-skin shows up within one refresh cycle of being published. A device with no SD card, or before anything's been published, shows the firmware's own built-in look.

See the server's [Theme](https://github.com/stumarti/Switchboard-Server/blob/main/wiki/Theme.md) page for the admin side.
